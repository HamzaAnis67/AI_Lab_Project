About Customer Churn Detection System

Project Overview

This Customer Churn Detection System is designed to help telecom companies identify customers who are likely to leave their service. By analyzing various customer attributes and usage patterns, the system predicts churn probability using machine learning algorithms.

Dataset Information

Dataset Details

  • Total Records: 7,043 customers
  • Features: 20 predictive attributes
  • Target Variable: Churn (Yes/No)
  • Source: Telco Customer Churn Dataset

Feature Categories

  • Demographics: Gender, Senior Citizen, Partner, Dependents
  • Services: Phone, Internet, Streaming, Security
  • Account: Contract, Billing, Payment Method
  • Financial: Tenure, Monthly Charges, Total Charges

Machine Learning Models

Logistic Regression

Best performing model with 81.55% accuracy. Provides interpretable results and probability scores.

Random Forest

Ensemble method with 79.91% accuracy. Robust to overfitting and provides feature importance.

K-Nearest Neighbors

Instance-based learning with 75.73% accuracy. Simple and effective for pattern recognition.

Decision Tree

Tree-based model with 72.46% accuracy. Easy to interpret and visualize decision rules.

Key Insights

  • Total Charges and Monthly Charges are the most influential factors in predicting churn
  • Customers with month-to-month contracts have higher churn rates
  • Tenure duration significantly impacts customer retention
  • Payment method preferences correlate with churn likelihood
